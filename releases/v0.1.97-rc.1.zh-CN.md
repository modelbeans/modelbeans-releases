# ModelBeans 0.1.97：第一次公开预览

[English](v0.1.97-rc.1.md)

这是一个个人业余项目，也是 ModelBeans 第一次与更多人见面。我希望把本地模型的下载、管理、运行、评测和工具连接放到一个平台里，让大家少花时间搭环境，多用模型做点事情。它还不完美，欢迎分享使用体验、成功运行的模型，以及遇到的问题。

## 下载和安装

- [直接下载 ModelBeans-0.1.97-win-x64.exe](https://github.com/modelbeans/modelbeans-releases/releases/download/v0.1.97-rc.1/ModelBeans-0.1.97-win-x64.exe)，适用于 Windows x64。完整包包含 RuntimeShare，模型需要另外下载。
- 安装包大小约 **629 MiB**。安装、共享运行时副本和临时解包都需要空间，建议在下载模型前预留至少 10 GiB；这不是所有模型的最低资源要求。
- 可同时下载 `.sha256` 校验文件、`SHA256SUMS.txt`、`release-manifest.json` 和许可证压缩包。
- 本预览版**未进行代码签名**。请核对官方仓库下载来源与 SHA256；校验和确认文件内容，不证明发布者身份。不要为了运行软件关闭系统防护。
- GitHub 自动生成的 **Source code** 压缩包只是本仓库的公开资料，不是应用安装包。

```powershell
Get-FileHash .\ModelBeans-0.1.97-win-x64.exe -Algorithm SHA256
```

完整包安装后，应用目录中的 `resources/runtime` 是随包运行时来源；共享运行时通常部署在 `%LOCALAPPDATA%\BeansAI\Runtime\versions\beansd-<标识>`，较长路径可能使用 `%LOCALAPPDATA%\BeansAI\r\<标识>`。状态与授权保存在 `%LOCALAPPDATA%\BeansAI\RuntimeShare`。无需用户手动复制 DLL 或清理这些目录。

## 这次可以尝试什么

- 从 Hugging Face 和魔搭 ModelScope 寻找、下载模型，或导入已有模型。
- 使用统一模型库管理文本、视觉、图片和音频相关模型；实际支持依模型格式、后端和设备而定。
- 使用本地 API、模型角色和别名，或连接 Claude Code、Codex CLI、OpenCode、WorkBuddy、DeepSeek Harness、Marvis。Marvis 需手动保存生成的接入信息。
- 使用内置智能体，选择本地或自行配置的云端模型，在指定工作目录中尝试小任务。
- 体验生图，以及语音生成、语音克隆、K 歌合成、音乐生成和声音设计五种实验性音频场景。
- 使用轻量性能与智能体就绪评测，为本机选模型提供参考。
- 参考 Python / Node.js 的独立子进程服务示例，为自己的应用接入本地推理。完整 SDK／独立开发者包后续单独提供。

## 本安装包的源码身份

本替换包包含已推送的服务启动改动，以及仅保留在本机的 Windows 安装器图标修复。`release-manifest.json` 记录了公开分支身份和本机精确构建提交，避免把这个二进制误认为由干净公开 checkout 可直接复现。

## 支持范围和验证情况

首发面向 Intel、AMD 集显 Windows 电脑。本轮在 Intel 集显开发机验证了原生后端启动及共享服务安装、重装和重启时无终端窗口。桌面连接及 Python / Node.js 真实 9B CPU 推理已在前一候选包验证；本次仅修改安装启动方式，复用相同的原生运行时，未重复全部模型验收。最终候选包在 AMD 机器上的完整回归仍待进行；此前 AMD 开发测试不替代本次验收。

随包后端包括 llama.cpp b12359、OpenVINO 2026.4.1 / GenAI 2026.4.1.0、ONNX GenAI 0.19.0、stable-diffusion.cpp master-1098-b521db4、audio.cpp 0.9.4 和 Strata 套件 0.2.13。Strata 内部引擎号 0.1.59 是不同组件的版本号，本 Windows 包使用 AMD HIP，不能在 Intel 集显上运行。

这些后端的验证深度并不相同。OpenVINO 本轮只验证原生库加载；音频仍是实验性功能；受保护的旧计划任务迁移未完成本轮验收。具体版本与限制见[兼容说明](../docs/compatibility.zh-CN.md)。

Linux 有相关实现，完成实机验证后再发布；独显适配与验证在后续取得硬件后推进。智能路由不作为本预览版的稳定功能承诺。第三方模型的工具调用、语言和生成质量也无法由平台保证。
