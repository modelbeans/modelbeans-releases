# ModelBeans 0.1.97: first public preview

[简体中文](v0.1.97-rc.1.zh-CN.md)

ModelBeans is a spare-time personal project, and this is its first public preview. I want model downloads, management, inference, evaluation and tool connections to work together in one platform, leaving more time to do something useful with local AI. It is still evolving; working model reports, bug reports and ideas are welcome.

## Download and install

- Download **ModelBeans-0.1.97-win-x64.exe** for Windows x64. RuntimeShare is included; model weights are downloaded separately.
- The installer is approximately **629 MiB**. Allow at least 10 GiB before downloading models for installation, shared runtime copies and temporary extraction. This is a practical recommendation, not a universal minimum for every model.
- Companion assets include the `.sha256` checksum, `SHA256SUMS.txt`, `release-manifest.json`, and a license archive.
- This preview is **not code-signed**. Verify the official repository download source and SHA256. Checksums verify contents, not publisher identity; do not disable system protection to run the application.
- GitHub's automatic **Source code** archives contain this repository's public materials, not the application installer.

```powershell
Get-FileHash .\ModelBeans-0.1.97-win-x64.exe -Algorithm SHA256
```

The application's `resources/runtime` directory supplies the bundled runtime. Installation normally deploys the shared runtime to `%LOCALAPPDATA%\BeansAI\Runtime\versions\beansd-<identity>`, with `%LOCALAPPDATA%\BeansAI\r\<identity>` as a shorter-path alternative. State and authorization live under `%LOCALAPPDATA%\BeansAI\RuntimeShare`. Manual DLL copying or directory cleanup is not required.

## What to try

- Find and download models through Hugging Face and ModelScope, or import existing files.
- Manage text, vision, image and audio models in one library. Compatibility depends on model format, backend and device.
- Use local APIs, model roles and aliases, or connect Claude Code, Codex CLI, OpenCode, WorkBuddy, DeepSeek Harness and Marvis. Marvis requires manually saving the generated connection details.
- Try the built-in agent with a local or separately configured cloud model in a workspace you choose.
- Explore image generation and five experimental audio workflows: speech generation, voice cloning, song covers, music generation and sound design.
- Run lightweight performance and agent-readiness checks to inform model selection.
- Explore Python / Node.js examples for an application-owned inference service. A complete SDK / standalone developer bundle will follow separately.

## Support and validation

The initial platform is Windows with Intel or AMD integrated graphics. This pass tested native backend startup and console-free shared-service installation, reinstallation and restart on the Intel development machine. Desktop connections and real 9B CPU inference through both embedded examples passed on the preceding candidate. This installer-only fix reuses the same native runtime; full model acceptance was not repeated. Full regression testing of this exact candidate on AMD is still pending; previous AMD development testing is not a substitute.

The bundle includes llama.cpp b12359, OpenVINO 2026.4.1 / GenAI 2026.4.1.0, ONNX GenAI 0.19.0, stable-diffusion.cpp master-1098-b521db4, audio.cpp 0.9.4, and Strata suite 0.2.13. Strata's internal engine version is 0.1.59, a separate component version. This Windows Strata bundle uses AMD HIP and does not run on Intel integrated graphics.

Validation depth varies by backend. This OpenVINO upgrade has native-library loading checks only; audio remains experimental; protected legacy scheduled-task migration was not tested in this pass. Read the [compatibility notes](../docs/compatibility.md) for versions and limitations.

Linux implementation exists, with a release planned after hardware validation. Discrete GPU integration will follow access to suitable hardware. Smart routing is not promised as a stable feature of this preview. Model-specific tool use, language support and output quality cannot be guaranteed by the platform.
