# ModelBeans 0.1.99

[简体中文](v0.1.99.zh-CN.md)

Full Windows x64 installer with RuntimeShare. Model weights are downloaded separately.

## Changes

- Fix RuntimeShare task registration failing with 0x80070057 on some Windows accounts. Use an unambiguous account identity and a native Task Scheduler fallback with limited user privileges.
- Retain protected legacy task handling, installation migration, hidden background startup, and M4A reference-recording support for song covers.
- Show one continuous bar with five stage dividers while a cover is running. Each completed stage advances it by 20%; this represents workflow stages, not elapsed or remaining time.
- Hide the bar after completion. Keep per-step models, durations and total time, without redundant text for steps that do not use a model.
- Retain the reference recording script, disabled Generate button during execution, long-song conversion windows and stage timing.

## Validation and limitations

- The user confirmed successful installation on Intel 258H and a complete local song cover with the preceding test package using the same installer scripts and native components. This release rebuilds the UI/version and reruns automated installer and UI checks.
- UI tests use fixtures, not real inference. The final package has not undergone another full AMD or cross-machine model acceptance run.
- Audio Studio remains experimental. Voice conversion can be slow: the user's approximately 6:31 song took about 48:11 to convert and 56:10 overall. This UI update does not claim faster inference.
- Windows Intel/AMD integrated graphics are the current development/use platforms; this does not certify every model, backend or driver combination. Linux and discrete GPU support have not been released as validated platforms.
- Respect the licenses and permissions for songs, reference voices and models.

Starting with this release, odd patch numbers identify tested stable releases; even patch numbers identify experimental GitHub Pre-releases. Release candidates use -rc.N.
