# 0.1.97 预览版：兼容范围与已知限制

[English](compatibility.md) · [快速上手](getting-started.zh-CN.md)

ModelBeans 在 Intel 和 AMD 集成显卡 Windows 电脑上开发。首次公开预览提供 Windows x64 完整安装包，包含 RuntimeShare；模型需另行下载。Linux 已有相关实现，完成实机验证后推出版本；独立显卡适配与验证属于后续计划。

不同显卡、驱动、模型架构和量化格式不能互相替代验收。最新候选包的 AMD / Strata 实机复核仍待完成，欢迎提供具体设备和模型的运行反馈。

## 安装与资源

- 安装包约 629 MiB，解包后的应用与运行时约 2.52 GiB。安装还需共享运行时副本、解压缓存和临时空间；建议先预留至少 10 GiB，再另算模型文件所需空间。这是安装空间建议，不是实测峰值或所有模型的最低要求。
- 模型文件大小不等于运行内存。上下文、输出规模、模型组件和其他程序都会占用内存；集显共享内存不能与系统内存重复相加。
- 本预览包未数字签名，Windows 可能显示未知发布者或 SmartScreen 提示。请核对 GitHub 下载来源与 SHA256；遇到阻止运行时记录提示并反馈。校验值确认文件内容，不替代发布者数字签名。
- 从 Release 的 **Assets** 下载安装器。GitHub 自动生成的 **Source code** ZIP 仅包含公开资料，不是软件安装包。

## 功能边界

- 智能体仍在改进，连接成功和工具就绪评测不保证复杂任务完成。先在独立练习目录尝试，检查工具权限和实际文件变更；自动智能路由不属于本次可用承诺。
- 音频工作室保留语音生成、语音克隆、K 歌合成、音乐生成、声音设计。声音克隆需匹配模型能力和参考音频，不保证每个模型、语言或素材都有理想效果。
- 客户端接入包括 Claude Code、Codex CLI、OpenCode、WorkBuddy、DeepSeek Harness、Marvis。自动配置范围因客户端而异；Marvis 需手动保存接入信息。API 兼容以具体端点为准。
- 内置性能与智能体就绪评测是选型参考，不是完整 BeansEval；后者后续独立发布。
- 嵌入示例用于独立服务进程集成。独立 RuntimeShare / SDK 开发者包尚未发布；请不要把示例目录当成完整 SDK 分发。
- 本地模型推理在本机执行；模型下载、云端模型和联网工具仍会使用网络。

反馈请附版本、系统、CPU/GPU、驱动、模型、后端和复现步骤，并去除密钥、个人路径和私人文件内容。
